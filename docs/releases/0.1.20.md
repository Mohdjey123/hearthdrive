A plugin store on computers, with seven plugins to start.

**Plugins (Windows)**

- **A new Plugins page.** Browse the plugins, see exactly what each one is allowed to do, and install the ones you want.
- **Seven plugins to start:**
  - **Web-sized photos:** smaller copies of photos, for sharing.
  - **Remove location from photos.**
  - **Contact sheet:** one image of a folder's thumbnails.
  - **Rename photos by date taken.**
  - **Text from documents.**
  - **Checksums:** a list for checking that files haven't changed.
  - **Folder contents list.**
- **Only the access you give.** Each plugin says what it needs: reading files, adding new files or renaming. It gets only that, and only in the storage locations you pick. If an update asks for more, the plugin stays off until you allow it.
- **Only the owner sets them up.** Plugins are installed and set up on the computer itself, so the page isn't on phones.
- **Folder plugins have moved.** Plugins you added with a plugin.json file are now on the Plugins page instead of in Settings.

Computers install updates by themselves once their HearthDrive window is closed.
