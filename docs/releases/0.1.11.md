A fix for the Android bottom bar.

**Fixes**

- **Android.** The Back button now closes the More sheet. After you pick a page from it, Back takes you to where you were, in one press.

Coming from 0.1.8 on Android? 0.1.8 can't open, so install this by hand: download `HearthDrive_0.1.11_arm64.apk` on the phone and open it. From 0.1.9 on, phones offer updates themselves.

| File | For |
| --- | --- |
| `HearthDrive_0.1.11_x64-setup.exe` | Windows 10/11, 64-bit |
| `HearthDrive_0.1.11_arm64.apk` | Android phones (64-bit ARM) |
