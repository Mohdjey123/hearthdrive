Commands on other devices work, from computers and phones.

**Fixes**

- **Commands on Devices.** Running a command on another device always failed. Now, from a computer or from the phone, open Devices, tap Commands on a device that is online and pick one: Look for changes, Check for updates, Pause transfers, Resume transfers, or Put to sleep (Windows computers only).
- **Who can run them.** The person running a command needs to be an owner or administrator on their own device, and that device needs the Editor role (the role devices are paired with) or higher on the other one. Each command is recorded in the other device's activity.

Update both ends: the device you use and the device you send commands to. Computers install updates by themselves once their HearthDrive window is closed.
