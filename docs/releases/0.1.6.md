NEXUS Cloud is now **HearthDrive**, with a new look.

**New name**

- The app, its window, the installer, Start menu and Desktop shortcuts, Installed apps, the Android app and the virtual drive in File Explorer are now called HearthDrive.
- Nothing else changes when you update. Your devices, pairings, settings, files and data folder stay where they were, and the old shortcuts are renamed.

**New look**

- A new logo: the hearth opening.
- Warm dark and light themes with an ember accent, and a new typeface (Source Sans 3, with Cascadia Mono for file names and sizes).
- New app icons on Windows and Android. On Android the icon takes your phone's icon shape.
- A clearer keyboard focus ring.

Coming from 0.1.4 or earlier? Install this by hand on one computer: it then passes the update on to all your other devices. From 0.1.5 on, every device finds updates here by itself.
