A fix for the Android app.

**Fixes**

- **Android.** HearthDrive 0.1.8 couldn't open on phones: it showed "HearthDrive did not start in time" even though it was running in the background. It opens again.

Because 0.1.8 can't open, a phone that has it can't offer you this update. Install this version by hand: open this page on the phone, download `HearthDrive_0.1.9_arm64.apk` and open it. Your pairings and settings stay as they are.

Coming from 0.1.4 or earlier? Install this by hand on one computer: it then passes the update on to all your other devices. From 0.1.5 on, every computer finds updates here by itself.

| File | For |
| --- | --- |
| `HearthDrive_0.1.9_x64-setup.exe` | Windows 10/11, 64-bit |
| `HearthDrive_0.1.9_arm64.apk` | Android phones (64-bit ARM) |
