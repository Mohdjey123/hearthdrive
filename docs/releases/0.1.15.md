Uploads from Android carry on in the background, with a notification that shows how far they've got.

**New on Android**

- **Background uploads.** Upload in Files now uses Android's own file picker. The files are sent by HearthDrive's background service, so they keep going if you switch apps or swipe HearthDrive away.
- **Transfers notification.** While uploads, backups or shared files are being sent, a notification shows the file count, the size and a progress bar. When they finish it says how many files were sent. If some failed, tap it to open Transfers and retry.

**Fixed**

- The Back up now shortcut opens the Backup page and asks you to set up backup first, instead of showing "Backup not found", when backup isn't set up yet.

Nothing changes on computers in this version.
