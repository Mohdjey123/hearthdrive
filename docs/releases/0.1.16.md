HearthDrive on Windows now waits in the system tray from the moment you sign in.

**Windows**

- **Start with Windows opens HearthDrive in the tray.** It used to start only the storage service, so the tray icon and notifications only appeared once you opened HearthDrive. Now the app starts hidden in the tray, which also starts the service. If Start with Windows is already on, it switches over the next time HearthDrive starts.
- **A more useful tray menu.** The tray shows what HearthDrive is doing: files being transferred and how far along they are, or how many of your devices are online. It also opens the HearthDrive folder in File Explorer (when the virtual drive is on), Transfers and Settings.
- **Updates no longer wait for Quit.** Updates install when no HearthDrive window is open. A window hidden in the tray used to count as open, so updates waited until you quit HearthDrive from the tray. Now they install while it sits in the tray, and HearthDrive comes back to the tray afterwards when Start with Windows is on. This takes effect from the update after this one.

Nothing changes on Android in this version.
