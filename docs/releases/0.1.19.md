HearthDrive on Windows keeps working in the background, and says so.

**Running in the background (Windows)**

- **A new section in Settings.** Running in the background brings it together: start at sign-in, what closing the window does, and sleep.
- **Closing the window.** Choose whether HearthDrive keeps running in the system tray (as before) or quits. The storage service keeps running either way, so your other devices can still reach this computer.
- **Start at sign-in, on from the start.** New setups end with "Start HearthDrive when I sign in to Windows" already ticked. If you set HearthDrive up earlier, turn it on in Settings › Running in the background.
- **No sleeping while files move.** The computer now also stays awake while another device, such as your phone, copies files to or from it, not only during its own transfers.
- **Full speed while busy.** While files are moving, HearthDrive asks Windows 11 not to slow it down with Efficiency mode. Once it is idle, Windows manages it as usual.

Computers install updates by themselves once their HearthDrive window is closed.
